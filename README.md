# 플레이볼

소리와 키보드로 즐기는 윈도우용 야구게임입니다. 이 저장소는 게임의 자동 업데이트와 오류 신고·건의를 관리합니다.

기존 배포 자료를 정리하고 버전 8.0부터 새로 시작합니다. 8.0은 이전 배포 파일에 의존하지 않는 기준 배포본입니다. 저장 경기와 사용자 설정은 유지됩니다.

배포자가 전달한 Playball.exe를 실행하면 필요한 게임 자료를 받아 시작합니다. 시작 프로그램 자체는 이 저장소에 게시하지 않습니다. 이용자는 GitHub 계정이나 로그인이 필요 없습니다.

처음에는 한국어에 필요한 자료만 설치합니다. 일본어와 영어 음성 엔진은 설정에서 선택할 때 추가 설치합니다. 설치 중에는 핫비트와 7초 간격 진행률 안내를 제공합니다. 이후 업데이트는 바뀐 자료 묶음만 받으며, 연결이 안 되면 설치된 정상 버전을 실행할 수 있습니다.

Windows 10 또는 11의 64비트 환경에서 사용합니다. 한국어·일본어·영어 중계를 선택할 수 있습니다.

오류 신고와 건의는 Issues에서 받습니다. 글 작성에는 GitHub 계정이 필요하지만 게임 자료 다운로드에는 필요하지 않습니다. 소스 코드는 공개하지 않습니다.
