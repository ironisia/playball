# 플레이볼

소리와 키보드로 즐기는 윈도우용 야구게임입니다. 이 저장소는 게임의 자동 업데이트, 오류 신고와 건의를 관리합니다.

배포자가 전달한 Playball.exe를 실행하면 필요한 게임 자료를 받아 시작합니다. 시작 프로그램 자체는 이 저장소에 게시하지 않습니다. 이용자는 GitHub 계정이나 로그인이 필요 없습니다.

처음 설치할 때는 전체 자료를 받고, 이후에는 바뀐 자료 묶음만 받습니다. 그대로인 음성 모델은 다시 받지 않습니다. 이미 받은 0.8 게임 자료도 검증하여 재사용하며, 저장 경기와 설정은 유지합니다. 업데이트 연결이 안 되면 설치된 정상 버전을 실행합니다.

Windows 10 또는 11의 64비트 환경에서 사용합니다. 한국어·일본어·영어 중계를 선택할 수 있습니다.

오류 신고와 건의는 Issues에서 받습니다. 글 작성에는 GitHub 계정이 필요하지만 게임 자료 다운로드에는 필요하지 않습니다. 소스 코드는 공개하지 않습니다.
