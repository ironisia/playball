# 플레이볼

소리와 키보드로 즐기는 윈도우용 야구게임입니다. 이 저장소는 게임의 자동 업데이트와 오류 신고·건의를 관리합니다.

현재 정식 배포 버전은 v0.84입니다. 저장 경기와 사용자 설정은 유지됩니다.

배포자가 전달한 최신 Playball.exe를 실행하면 필요한 게임 자료를 받아 시작합니다. 시작 프로그램 자체는 이 저장소에 게시하지 않습니다. 이용자는 GitHub 계정이나 로그인이 필요 없습니다.

처음 설치할 때 한국어·일본어·영어 음성 엔진을 포함한 모든 게임 자료를 함께 설치합니다. 설치 후에는 언어를 바꿀 때 추가 다운로드가 필요하지 않습니다. 설치 중에는 핫비트와 7초 간격 진행률 안내를 제공합니다. 이후 업데이트는 바뀐 자료 묶음만 받으며, 연결이 안 되면 설치된 정상 버전을 실행할 수 있습니다.

Windows 10 또는 11의 64비트 환경에서 사용합니다. 한국어·일본어·영어 중계를 선택할 수 있습니다.

오류 신고와 건의는 Issues에서 받습니다. 글 작성에는 GitHub 계정이 필요하지만 게임 자료 다운로드에는 필요하지 않습니다. 소스 코드는 공개하지 않습니다.
