# 플레이볼

소리와 키보드로 즐기는 윈도우용 야구게임입니다. 이 저장소에서는 완성된 게임의 배포와 업데이트, 오류 신고 및 건의를 관리합니다.

## 시작하기

[플레이볼 실행기 다운로드](https://github.com/ironisia/playball/releases/download/launcher-v1/PlayballLauncher.exe)

다운로드한 PlayballLauncher.exe를 실행하면 최신 게임을 받아 시작합니다. 이용자는 GitHub 계정이나 로그인이 필요 없습니다. 처음 다운로드할 때는 인터넷 연결이 필요합니다. 이후 업데이트 확인에 실패하면 이미 설치된 정상 버전을 실행합니다.

Windows 10 또는 11의 64비트 환경을 사용해 주세요. 게임에서 한국어·일본어·영어 중계를 선택할 수 있습니다. 게임 저장과 설정은 업데이트 때 유지됩니다.

오류 신고와 건의는 이 저장소의 Issues에 남길 수 있습니다. GitHub에 글을 작성하려면 GitHub 계정이 필요하지만 게임 다운로드에는 필요하지 않습니다.

이곳에는 완성된 배포 파일을 제공합니다. 게임의 소스 코드를 공개하는 저장소는 아닙니다.
